# Historical experiments

These are preserved source snapshots, not default runtime commands or automated tests. Many scripts connect to real browser sessions or change Windows/browser state. Root-relative paths in legacy snapshots describe their original environment and are intentionally preserved for review.

The maintained clone entry is tools/session-cloner/reproduce_profile_capsule.ps1. Maintenance repair code remains tied to its historical date and must be reviewed before explicit use. Do not batch-run files based on test_* names.

# Codex Bridge ChatGPT Public V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a locally committed, Plugin-ready open-source V1 that Mac and Windows ChatGPT desktop users can install and invoke with one sentence.

**Architecture:** Keep one canonical Skill under `skills/codex-bridge-chatgpt`; wrap it with a root Plugin manifest and public documentation. Add a dependency-free local Doctor plus Skill-driven Browser preflight, while retaining the existing bounded Packet, Result, adoption, and receipt gates.

**Tech Stack:** Markdown, JSON, YAML, Node.js standard library, Node test runner, GitHub Actions, Codex Skill and Plugin manifests.

## Global Constraints

- V1 supports Codex only in Mac and Windows ChatGPT desktop apps.
- The public invocation remains `$codex-bridge-chatgpt <task>`.
- Automatic Doctor runs before every handoff and resumes the original task after human login or model selection.
- No external npm package, API key, MCP server, browser extension, or background service.
- Production paths and tests must not depend on symlinks or `/Users/...` paths.
- Version is `0.1.0`; license is MIT; intended GitHub repository is `https://github.com/anightmonarch/codex-bridge-chatgpt`.
- Public repository creation and push remain outside this plan's automatic authority.
